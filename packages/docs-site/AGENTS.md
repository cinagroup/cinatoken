# CinaToken 文档站

本目录使用 Astro + Starlight，维护面向 CinaToken 用户的原创中英文帮助文档。
工程与部署的权威文档仍在仓库根 `docs/`。不要批量覆盖或改写历史发布说明。

- 页面放在 `src/content/docs/{en,zh}/docs/`，同一路径必须同时有中英文版本。
- 保持 `/{locale}/docs/` 文档路径与 `/docs-assets/` 资源命名空间；禁止接管产品首页、`/api`、账户或管理路径。
- 模型能否调用、价格和余额以现有 API 与界面为准，不把上游模板当成已上线服务。
- 不从未声明复用许可的仓库复制源码、文章、截图或目录数据。上游调研的固定提交见 README。
- 不添加第三方统计、远程字体或浏览器端密钥。
- 修改后运行 `npm run check:docs-site` 和 `npm run build:web`；资源复制与摘要绑定由 Web 构建插件执行。
- 所有重型检查使用父目录的共享串行验证脚本。
