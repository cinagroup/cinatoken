MCP 入口聚合已配置的远程服务与工具。是否可用取决于实例配置、目录状态和调用方权限。

## 操作步骤

1. 由管理员配置服务、同步工具目录并审核条目变化。
2. 在客户端填写管理员提供的 MCP 地址，按服务公布的认证流程授权。
3. 先发现可用工具，再验证受控调用及审计记录。

## 核对范围

普通账户登录、模型调用密钥和 MCP OAuth 授权不能随意互换。
