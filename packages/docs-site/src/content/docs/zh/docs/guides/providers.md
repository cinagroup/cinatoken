供应商（Providers）配置上游服务的地址、协议与认证；它与公开模型条目分别维护。

## 操作步骤

1. 在管理控制台选择供应商模板，核对区域、协议和地址。
2. 通过管理界面保存上游凭据，再配置对应的模型端点与路由。
3. 验证单条上游连接及正式网关请求，最后确认公开发布状态。

## 核对范围

导入模板不会自动开通上游账号、额度、路由或公开模型。
