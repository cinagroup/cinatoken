智能体工具（Tools）通过网关封装可配置的搜索、抓取等服务；底层引擎需由管理员配置。

## 操作步骤

1. 在工具配置中核对启用状态、底层引擎和所需认证。
2. 确认调用方有相应权限，并按 /v1/tools/* 的具体接口约定填写请求。
3. 先验证工具配置，再用真实代理请求检查结果、用量与日志。

## 核对范围

管理端的引擎测试与正式网关调用具有不同的路径与计费边界。
