系统配置（System configuration）影响实例级行为。先确认运行环境和权限，再修改具体设置。

## 操作步骤

1. 定位需要修改的配置组，核对单位、币种、时区与当前值。
2. 提交一组明确的变更，确认服务器回执与刷新后的状态。
3. 按配置说明复测新请求或刷新缓存，并检查审计记录。

## 核对范围

配置导入与恢复应使用对应版本的工程流程，不以网页批量覆盖替代迁移。
