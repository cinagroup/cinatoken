概览与统计用于观察请求、延迟、费用和故障趋势；查询范围决定指标含义。

## 操作步骤

1. 在 /admin 选择时间段，并确认是否启用自动刷新。
2. 对比模型、供应商与用户维度，结合延迟分位数和失败汇总判断变化。
3. 用具体请求日志验证异常，涉及结算时再核对正式流水。

## 核对范围

数据验证失败时不会显示正常统计；空白不能解释为零费用或零请求。
