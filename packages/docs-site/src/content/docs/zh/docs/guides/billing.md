请求费用、周期额度、永久额度与密钥消费限制需要在各自的币种、单位和范围内核对。

## 操作步骤

1. 核对模型价格与适用路由的输入、输出、缓存及时间段配置。
2. 检查密钥、工作区与账户限制；其中任意一层都可能拒绝请求。
3. 以请求 ID 对照活动与正式结算记录，区分消费和共享密钥收益。

## 核对范围

模型、图片、音频与工具可能使用不同计量单位；静态参考价不是正式结算凭证。
