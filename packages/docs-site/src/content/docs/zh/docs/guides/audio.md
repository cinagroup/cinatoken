语音转写、语音合成与实时语音分别使用对应模型、协议和计量方式。

## 操作步骤

1. 确认 ASR、TTS 或实时语音能力和可用端点。
2. 按接口要求使用 /v1/audio/transcriptions、/v1/audio/speech 或受支持的实时入口。
3. 检查文件类型、语言、音色、响应格式以及时长、字符或 token 计量。

## 核对范围

上传音频不等于允许浏览器使用麦克风；需要录音时由用户单独授予权限。
