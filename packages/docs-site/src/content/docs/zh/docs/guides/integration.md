业务系统通过服务端集成账户、工作区和网关调用；管理权限与推理权限分别处理。

## 操作步骤

1. 明确用户、工作区和应用的对应关系，避免跨工作区复用密钥。
2. 让服务端保存管理凭据，为实际调用方分发受限的网关调用密钥。
3. 核对接口错误、主体身份与重试结果，保留请求或审计 ID。

## 核对范围

门户业务元数据由业务系统解释，不能依赖代理服务隐式改变其含义。
