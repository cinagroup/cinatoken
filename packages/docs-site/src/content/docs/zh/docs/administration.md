## 进入管理控制台

从[管理控制台](/admin)完成 CinaAuth 管理员验证。服务端会校验实际角色；前端显示入口并不等同于授予权限。

账户中心管理自己的工作区和调用密钥。管理控制台配置平台资源、查看受权限约束的全局记录；管理概览在 `/admin`，旧 `/dashboard` 书签会跳转到这里。

## 模型发布顺序

1. 在供应商（Providers）中配置供应商与认证信息。
2. 在模型（Models）中核对调用 ID、能力和计费配置。
3. 在端点（Endpoints）中配置匹配的协议入口并完成验证。
4. 在路由（Routes）中连接模型与可用供应商，确认启用状态。
5. 完成公开发布所需的检查，再从公开目录和实际调用验证结果。

导入目录模板不等于完成部署。端点验证结果也可能过期；以当前界面状态为准。不要将内部备注、供应商密钥或管理端点配置放入公开说明。

## 变更前后核对

记录变更对象与预期效果，优先在小范围验证。检查路由、币种、价格、时段、权限和审计记录。删除、停用或调整计费前应了解现有调用方。

完整工程与运维说明见[仓库文档](https://github.com/cinagroup/cinatoken/blob/main/docs/README.md)。这份用户指南不替代部署流程和生产迁移检查。
