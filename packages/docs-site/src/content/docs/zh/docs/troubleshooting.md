## 登录问题

“登录未完成”请先按[登录说明](/zh/docs/authentication/)重新完成一次认证。管理员入口与普通账户的验证意图不同；需要管理员访问时从 `/admin` 开始。

## API 错误

| 现象 | 先检查 |
| --- | --- |
| `401` | 是否使用网关调用密钥、是否已吊销或过期、请求头格式是否正确 |
| `403` | 当前密钥、账户、工作区是否有该资源和操作的权限 |
| `404` 或模型不可用 | 服务地址和模型调用 ID 是否正确，实时目录是否仍有该模型 |
| 额度或计费拒绝 | 密钥上限是否为 `0`，工作区与账户限制是否已达到 |
| `429` | 速率限制或上游容量；遵循响应的重试提示并退避 |
| `5xx`、超时或断流 | 保存请求 ID，稍后有限次数重试；避免重复提交长请求 |

不要通过禁用认证、暴露管理员密钥或无上限重试来绕过错误。

## 页面数据无法验证

如果出现 “Dashboard data could not be verified” 或类似提示，页面没有拿到符合约定的有效响应。刷新一次；仍失败时记录时间、页面路径和报错。不要把该状态当成零用量。

## 提供排查信息

向管理员提供：时间与时区、页面路径或 API 路径、模型 ID、HTTP 状态、请求 ID、脱敏后的错误文字。不要提供完整密钥、Cookie、登录回调参数或敏感输入。
