## 选择正确的密钥

| 类型 | 用途 |
| --- | --- |
| 网关调用密钥（Gateway API key） | 应用调用 CinaToken 的推理 API |
| 供应商密钥 | 连接上游模型服务；由供应商配置或个人密钥功能管理 |
| 管理密钥（Management API key） | 调用获授权的管理接口，不能作为普通推理密钥替代使用 |
| 浏览器登录会话 | 访问账户和管理页面，不应复制给应用使用 |

## 创建与限制

在[账户中心](/account)确认工作区，再创建网关调用密钥。建议每个应用、环境使用独立密钥，设置可接受的消费上限和过期时间。

消费上限为 `0` 会阻止计费调用；不填写表示不设置该密钥级上限，仍然受工作区和账户限制。周期额度按界面注明的 UTC 边界重置。

完整密钥仅在创建时展示。如果创建结果不明确，先刷新列表确认，避免重复创建。

## 轮换与吊销

先创建新密钥并更新应用配置，确认调用成功后再吊销旧密钥。发现泄露时立即吊销，检查[活动记录](/account/activity)，并排查使用该密钥的应用和日志。

不要把网关调用密钥放进公开网页源码，也不要用管理员密钥测试公开聊天。
