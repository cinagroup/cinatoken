网关支持多种请求协议，但每个模型只开放已配置且验证通过的能力。

## 操作步骤

1. 先在实时模型目录确认调用 ID、输入类型和可用能力。
2. 选择与客户端匹配的请求入口；同一模型的 Chat、Responses 或其他协议可有不同路由。
3. 用小规模样本验证输入、输出和限制，再接入正式工作负载。

## 核对范围

成功的短文本请求不能证明图片、音频或工具参数也受支持。
