CinaToken 将模型调用、密钥和用量管理放在同一平台。先完成一次调用，再按需要配置客户端和额度。

## 建议的使用顺序

1. [快速开始](/zh/docs/quickstart/)：登录、创建密钥并发起请求。
2. [选择模型](/zh/docs/models/)：查看当前公开模型与支持的能力。
3. [接入 API](/zh/docs/api/)：使用命令行或兼容客户端。
4. [查看用量](/zh/docs/usage/)：核对请求、额度和结算记录。

## 常用入口

| 入口 | 用途 |
| --- | --- |
| [模型目录](/zh/models) | 查看当前公开的模型、能力和价格信息 |
| [聊天](/zh/chat) | 在浏览器中使用自己的网关调用密钥测试模型 |
| [账户中心](/account) | 管理当前工作区的密钥、活动和设置 |
| [管理控制台](/admin) | 管理员配置供应商、模型、端点和路由 |

公开模型目录来自运行中的服务。参考资料中的模型名称或上游模板，不代表该模型已在 CinaToken 上开通。

这些文档介绍托管的 CinaToken 服务。自托管部署与工程配置请参阅 [GitHub 工程文档](https://github.com/cinagroup/cinatoken/blob/main/docs/README.md)。
