维护模式用于在计划窗口中控制推理与管理写入，具体只读例外以工程约定为准。

## 操作步骤

1. 确认维护范围、负责人、当前发布版本和数据库备份。
2. 按维护文档进入窗口，检查推理与管理写入的拒绝行为。
3. 完成变更与就绪检查后恢复服务，并复核关键接口。

## 核对范围

维护期间的拒绝响应不等于某个用户的额度为零。
