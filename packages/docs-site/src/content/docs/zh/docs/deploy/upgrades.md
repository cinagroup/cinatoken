升级应以明确的版本、迁移要求和冻结产物为单位，保留可核对的回退路径。

## 操作步骤

1. 阅读目标版本的变更与迁移说明，保存当前版本及配置记录。
2. 在隔离环境完成检查，按既定顺序执行迁移与应用发布。
3. 切流后检查关键业务和旧资源，出现问题按对应回退说明处理。

## 核对范围

回退网页入口不会自动撤销数据库、资金记录或外部操作。
