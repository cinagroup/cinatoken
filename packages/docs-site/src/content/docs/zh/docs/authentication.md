## 登录账户中心

CinaToken 使用 CinaAuth 管理身份。点击登录后，在认证窗口中完成验证，等待窗口关闭并返回原页面。浏览器会话用于网页访问；API 调用需要单独的网关调用密钥。

如果认证窗口被浏览器拦截，请允许本站打开登录窗口，然后重新点击登录。不要把认证窗口中的地址或一次性代码发给他人。

## 工作区

账户中心上方可切换可用工作区。切换后，请重新确认密钥所属工作区以及当前看到的记录。不同工作区的数据不能混用。

## 管理员入口

拥有服务端管理员权限的账户可以进入[管理控制台](/admin)。看不到入口时，直接打开该地址并按提示完成管理员验证。

仅登录普通账户不会自动获得管理员权限。若管理员角色刚刚调整，请退出后从管理员入口重新登录；仍无法访问时，由现有管理员核对角色。

## 登录未完成

1. 关闭旧的认证窗口，从当前 CinaToken 页面重新开始。
2. 确认认证完成后回到同一个浏览器和页面。
3. 使用页面的重试操作刷新会话；不要反复并行打开多个登录窗口。
4. 如果仍失败，记录报错文字、发生时间和页面地址，提供给管理员。不要提供 Cookie 或完整回调地址。
