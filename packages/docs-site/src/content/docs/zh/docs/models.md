## 以实时目录为准

在[模型目录](/zh/models)查看当前公开的模型，并复制其调用 ID。目录随管理员配置与验证结果变化，文档不固定承诺模型数量或某个型号永久可用。

模型列表、价格信息和可调用路由不是同一个概念。看得到某个模型，不代表当前密钥、工作区、请求入口和参数组合一定能调用。

## 先核对这些信息

- 输入类型：文本与图片输入分别确认。
- 输出与上下文限制：总上下文长度不等于最大输出长度。
- 请求入口：客户端协议应与模型可用端点匹配。
- 价格：核对币种、输入、输出、缓存及适用时段。

[比较页面](/zh/compare)可帮助对照公开模型信息。排名和基准数据的来源或更新时间应分别确认，不能替代你自己的任务测试。

## 先做小范围验证

先发送短文本，再使用真实但不含敏感信息的样本测试。增加图片或工具参数前核对该能力；同一供应商下不同型号的能力可能不同。

上游模型模板仅用于配置参考，导入模板后仍需配置端点、路由、密钥和公开发布验证。
