## 查看当前范围

先在[账户中心](/account)确认工作区，再查看[活动记录](/account/activity)。密钥列表和工作区切换会影响当前展示的数据范围。

## 价格与消费限制

公开目录的模型价格是调用前的参考。请求的实际费用还取决于适用路由、输入与输出量、缓存命中、计费配置及适用时段。按页面展示的币种和单位核对，不要把不同币种直接相加。

密钥级上限、工作区额度和账户约束可以同时生效。增加某一个上限，不一定解除其他限制。周期额度的重置时间以界面显示为准。

## 核对一笔请求

记录调用时间、模型 ID、HTTP 状态和请求 ID，再对照活动记录。只提供排查所需信息；删除密钥、个人信息和敏感输入。

共享密钥收益、提现和链上记录使用各自的状态与单位，不能直接当作推理消费余额。相关操作前请阅读该页面的条件、手续费和网络说明。

## 数据暂时不可用

如果页面明确提示无法验证数据，请刷新或稍后重试。空白或加载失败不表示余额为零，也不表示请求一定未执行。
