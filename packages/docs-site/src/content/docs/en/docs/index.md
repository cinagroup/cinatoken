CinaToken brings model access, API keys and usage management into one platform. Start with a working request, then configure your clients and limits.

## Get started

1. [Quickstart](/en/docs/quickstart/): sign in, create a key and send a request.
2. [Choose a model](/en/docs/models/): check the current public catalog and capabilities.
3. [Use the API](/en/docs/api/): connect with curl or a compatible client.
4. [Review usage](/en/docs/usage/): check activity, limits and settlement records.

The public model catalog comes from the running service. A model mentioned in reference material or an upstream template is not necessarily available through CinaToken.

These guides cover the hosted CinaToken service. For self-hosting and engineering configuration, see the [repository documentation](https://github.com/cinagroup/cinatoken/blob/main/docs/README.md).
