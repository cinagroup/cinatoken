The gateway supports multiple protocols. Each model exposes only the capabilities configured and verified for it.

## Workflow

1. Check the live catalog for a callable ID, input types and available capabilities.
2. Choose a matching request surface; Chat, Responses and other protocols may use different routes for the same model.
3. Validate a small sample and its limits before connecting a production workload.

## What to verify

A successful text request does not prove support for images, audio or tools.
