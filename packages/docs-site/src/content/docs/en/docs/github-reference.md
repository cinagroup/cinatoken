These guides cover the hosted service. Engineering documentation defines the full API, configuration, deployment and migration contracts.

## Workflow

1. Users should begin with quickstart, keys and model selection.
2. Integrators should verify authentication, fields, errors and currencies in the API reference.
3. Self-hosting operators should follow deployment instructions and migrations for their exact version.
