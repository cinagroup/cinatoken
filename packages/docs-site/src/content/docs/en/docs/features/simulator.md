Simulator sends calls through the real proxy, rather than providing an offline preview.

## Workflow

1. Choose an authorized Gateway API key, model and request surface.
2. Review outgoing parameters and start with a minimal sample.
3. Use the request ID to check authentication, routing, usage, charges and logs.

## What to verify

Simulator can incur real charges. A successful Playground test does not prove the production path works.
