## Check the scope

Confirm the workspace in your [account](/account), then open [activity](/account/activity). Workspace selection and key ownership determine which data is shown.

## Prices and limits

Public model prices are a pre-request reference. Actual charges also depend on the applicable route, input and output usage, cache hits, billing configuration and time window. Check the currency and units displayed; do not combine amounts in different currencies directly.

Key caps, workspace budgets and account restrictions may apply together. Raising one limit does not necessarily remove another restriction. Use the reset times shown in the interface for recurring budgets.

## Reconcile a request

Record the time, model ID, HTTP status and request ID, then compare them with activity records. Share only what is needed for diagnosis, removing keys, personal information and sensitive inputs.

Shared-key earnings, withdrawals and on-chain records have their own states and units. Do not treat them as inference balance. Read the relevant page's conditions, fees and network information before acting.

## Data is unavailable

If a page says it could not verify data, refresh or try again later. Missing data is not a zero balance and does not prove a request was never executed.
