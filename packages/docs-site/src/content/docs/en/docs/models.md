## Use the live catalog

Browse the [model catalog](/en/models) and copy a callable ID. Availability follows administrator configuration and verification; documentation does not promise a permanent model count or a particular model indefinitely.

A catalog entry, a price and a callable route are distinct. Visibility does not guarantee that your key, workspace, request surface and parameters can use every model.

## Check before calling

- Input types: verify text and image support separately.
- Context and output: a context window is not the maximum output length.
- Request surface: match the client's protocol to an available endpoint.
- Pricing: check currency, input, output, caching and applicable time windows.

Use [compare](/en/compare) to review public specifications. Check the source and date of rankings and benchmarks separately; they do not replace testing on your own tasks.

## Validate a small request first

Start with a short text request, then test representative samples without sensitive data. Check image or tool support before adding those parameters. Models from the same provider may support different capabilities.

Upstream model templates are configuration references. Importing one still requires endpoints, routes, keys and public-release verification.
