Request Logs connect calls, routes and usage. Start diagnostics with the request ID.

## Workflow

1. Filter by time, model, user or state, checking timezone and scope.
2. Inspect the request surface, selected route, failure stage and usage in the detail view.
3. Compare sanitized errors with client records before a controlled reproduction.

## What to verify

A failed log load is not evidence of no requests. Keep full keys out of diagnostic material.
