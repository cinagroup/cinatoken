Providers configure upstream URLs, protocols and authentication, separately from public model entries.

## Workflow

1. Choose a provider template in the console and check its region, protocol and URL.
2. Save upstream credentials through the management interface, then configure model endpoints and routes.
3. Verify both the individual upstream connection and a real gateway request before checking publication.

## What to verify

Importing a template does not create an upstream account, budget, route or public model.
