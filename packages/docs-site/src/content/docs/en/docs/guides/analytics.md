Analytics summarize requests, latency, costs and failures; their meaning depends on the selected scope.

## Workflow

1. Select a time range at /admin and check automatic refresh settings.
2. Compare model, provider and user views alongside latency percentiles and failure summaries.
3. Validate anomalies with request details and use settlement records for financial reconciliation.

## What to verify

Invalid responses are not normal statistics. Missing data does not mean zero costs or requests.
