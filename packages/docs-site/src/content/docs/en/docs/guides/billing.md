Request charges, recurring budgets, permanent credit and key limits must be checked in their own currency, unit and scope.

## Workflow

1. Review input, output, cache and time-window pricing for the applicable route.
2. Check key, workspace and account limits; any applicable layer can reject a request.
3. Reconcile request IDs with activity and settlement records, keeping spending separate from shared-key earnings.

## What to verify

Models, images, audio and tools may use different units. Reference prices are not settlement receipts.
