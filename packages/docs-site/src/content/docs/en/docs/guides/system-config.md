System configuration controls instance-level behavior. Confirm the environment and permissions before editing a setting.

## Workflow

1. Identify the configuration group and verify units, currency, timezone and current values.
2. Submit a defined change and confirm its server receipt and refreshed state.
3. Retest requests or refresh caches as documented, then review the audit record.

## What to verify

Use the engineering procedure for versioned configuration import or recovery; bulk editing is not a migration.
