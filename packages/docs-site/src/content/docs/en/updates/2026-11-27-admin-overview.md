The console overview now uses `/admin`. Existing `/dashboard` bookmarks preserve their query filters when redirecting. Account pages continue to manage the current user’s workspace and Gateway API keys.

The overview includes period comparisons, latency percentiles, cost efficiency, failure summaries and optional refresh. Data is shown only after a valid response; verification failures do not mean zero usage or charges.
