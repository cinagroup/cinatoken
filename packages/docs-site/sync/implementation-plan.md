- Web 生产版本 `2a789976-171b-4a9a-a5d2-3df30a4a8f87`；冻结产物 `production-20261128-docs-8fbaa084eeab`。

1. 全文搜索：中英文实际查询、键盘操作、空结果与失败状态；索引使用完整内容摘要目录，旧索引随旧资源保留；Worker/Nginx 缓存、CSP、冻结产物和源码映射覆盖所有索引文件。
2. 完整指南：覆盖调研网站的 30 个主题，包括协议、客户端、供应商、路由、额度、日志、工具、OAuth/MCP、运维、升级和技术参考；适配 CinaAuth 与实际托管服务。工程权威文档仍在根 `docs/`，历史事实保持来源身份。

6. 同步治理：固定来源提交、逐文件摘要与生成清单；显式更新命令、漂移检查与 PR 审阅，不自动发布价格；技术文档链接与目录来源可追溯。
7. 发布与回退：同域导航、双语与日/韩英文回退、canonical/hreflang/站点地图；原有登录/业务请求边界保持；完整类型/格式/测试/构建、Docker HTTP 与浏览器桌面手机验收；合并、精确 CI 产物部署、全部资源核对及任务分支清理。
