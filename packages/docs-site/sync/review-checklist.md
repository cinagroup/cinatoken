# 网站来源更新审阅

生成的补丁只能经人工审阅、PR 检查与正常部署后发布，不自动导入生产模型或调整线上价格。

- 核实来源仓库、完整提交、许可范围和逐文件摘要；上游更新仅含日期、版本和原文链接。
- 检查模型新增、删除、退休状态、价格、币种和能力变化，确认展示的是配置参考。
- 检查供应商协议、端点与公开链接；不得发布 `managed_environment_key`、令牌或部署私有字段。
- 保持 CinaToken 与 OctaFuse 的更新身份、日期和版本证据，检查中英文页面。
- 运行 `check:sync`、文档构建、Admin 目录兼容测试、Web 类型/格式/测试与 Docker HTTP 检查。
- PR 描述列出来源提交、模型/供应商数量变化、价格变化和验证；新 feed 上线后才切换 Admin 来源。
- 部署保留上一冻结产物；验收全文搜索、旧索引、目录筛选、JSON feed、登录和管理导入预览。
