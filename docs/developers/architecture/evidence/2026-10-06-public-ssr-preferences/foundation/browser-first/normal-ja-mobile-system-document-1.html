CinaToken Gateway

AI リソースをひとつに。

モデル、ツール、独自プロバイダーを統合するゲートウェイ。ワークスペースからアクセス、予算、利用状況を管理します。

アカウントを開くモデルを見るコンソールへドキュメントを見る

機能アーキテクチャデプロイ

POST https://api.cinatoken.com/v1/chat/completions

リクエスト

{
  "model": "your-model",
  "messages": [
    {
      "role": "user",
      "content": "挨拶してください。"
    }
  ]
}

レスポンス

{
  "object": "chat.completion",
  "choices": [
    {
      "message": {
        "content": "..."
      }
    }
  ]
}

リクエストとレスポンスの例です。実際のリクエストは送信されません。

リソースを接続
統一 API を通じて、モデルプロバイダーとエージェントツールを共有ゲートウェイに接続します。
アクセスと予算を管理
API キー、ワークスペース権限、利用予算をアカウントで管理します。
利用状況を把握
実際のリクエスト、ルーティング判断、会計記録を一か所で確認します。

ビルダーのための AI ケイパビリティゲートウェイ

柔軟な接続、インテリジェントなルーティング、コスト制御、エンドツーエンドの可観測性。

/v1/chat/completions/v1/responses/v1/images/*/v1/audio/*/v1/tools/*

統一プロトコル

一つの Gateway Base URL からモデル推論、メディア機能、エージェントツールを利用できます。

Chat · Responses · Images · Audio · Tools

インテリジェントルーティング

各リクエスト入口をルートプールへ送り、複数のアップストリーム間で安全にフェイルオーバーします。

優先度 · Weight · フェイルオーバー · Sticky routing

予算とキー

利用者ごとにキーを発行し、期間予算と実使用量でコストを管理します。

ユーザー · API Key · 期間予算 · 3 つの台帳

ログと分析

呼び出し経路と予算イベントを記録し、利用量、コスト、品質を多角的に確認します。

リクエストログ · 監査ログ · モデル/Provider/ユーザー分析

Provider から安定した呼び出しまで、4 ステップ

  1. 1

    Provider を接続

    アップストリームのエンドポイントと認証情報を設定

  2. 2

    モデルとルートを公開

    プロトコル入口、ルートプール、フェイルオーバーを定義

  3. 3

    ユーザーキーを発行

    ユーザー、プロジェクト、顧客ごとに API Key と予算を割り当て

  4. 4

    すべての呼び出しを観測

    ログ、監査、分析で継続的に改善
