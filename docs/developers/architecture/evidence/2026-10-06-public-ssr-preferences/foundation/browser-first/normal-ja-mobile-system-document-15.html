기능아키텍처배포

POST https://api.cinatoken.com/v1/chat/completions

요청

{
  "model": "your-model",
  "messages": [
    {
      "role": "user",
      "content": "인사해 주세요."
    }
  ]
}

응답

{
  "object": "chat.completion",
  "choices": [
    {
      "message": {
        "content": "..."
      }
    }
  ]
}

요청과 응답 예시이며 실제 요청은 전송하지 않습니다.

리소스 연결
일관된 API로 모델 공급자와 에이전트 도구를 공유 게이트웨이에 연결하세요.
접근과 예산 관리
계정에서 키, 워크스페이스 권한, 사용 예산을 관리하세요.
사용 현황 확인
실제 요청, 라우팅 결정, 회계 기록을 한곳에서 확인하세요.

Chat · Responses · Images · Audio · Tools

지능형 라우팅

각 요청 진입점을 라우트 풀로 보내고 여러 업스트림 대상 간에 안전하게 장애 조치합니다.

우선순위 · 가중치 · 장애 조치 · 고정 라우팅

예산과 키

실제 사용자에게 별도 키를 발급하고 주기 예산과 실제 사용량으로 비용을 제어합니다.

사용자 · API Key · 주기 예산 · 3개 원장

로그와 분석

호출 경로와 예산 이벤트를 기록하고 사용량, 비용, 품질을 여러 관점에서 확인합니다.

요청 로그 · 감사 로그 · 모델/Provider/사용자 분석

Provider 연결부터 안정적인 호출까지 4단계

  1. 1

    Provider 연결

    업스트림 엔드포인트와 자격 증명 구성

  2. 2

    모델과 라우트 게시

    프로토콜 진입점, 라우트 풀, 장애 조치 정의

  3. 3

    사용자 키 발급

    사용자, 프로젝트, 고객별 API Key와 예산 할당

  4. 4

    모든 호출 관측

    로그, 감사, 분석으로 지속적으로 개선
