# C02 v284：同次候选的只读预检证据收集

2026-09-21，完成来源、旧代码和套餐观察的组合收集层，最终 **185 项本地验证通过**。真实冻结产物接线使用 **19 次合成 GET、0 次真实云调用**，返回 `PARTIAL_EVIDENCE_COLLECTED`，不是完整预检许可。

## 已接通的部分

新增 `scripts/deploy/byok-d1-preflight-evidence.mjs` 与专项测试：

1. 将候选完整 deployment fingerprint、runId、prior manifest 与完整 observer baseline 的 `scopeSha256` 固定到同一身份。检查三份候选的 prior worker 与 baseline 一致，并保留操作器要求的一个撤销 Token 观察位置。
2. 接受 v283 的**活跃来源检查对象**和其封存结果；核对摘要、候选绑定及源码当前状态。进一步检查实际正在运行的预检 bundle / metafile 已在该来源证据内，其 **347 个输入文件**均已固定。未列出的内部依赖、外部第三方运行时依赖和未冻结的执行产物被拒绝；仅允许主机 Node 内置依赖。
3. 在独立的 `byok-d1-preflight-evidence-reservation` 内收集，不能消耗真正的 `byok-d1-execution-reservation`。已有只读预约不可重跑；存在目标 workspace 的执行预约时拒绝收集。本轮真实项目根目录的执行预约始终不存在。
4. 复用真实实现的旧代码与套餐收集器，固定 **15 + 4 = 19 次 GET**、最多四个等待响应头的请求、整体最多 60 秒。仅允许固定账户的三个既有 Worker 代码 / settings / deployments，以及账户配置 / subscriptions；拒绝其他路径、请求体、重定向和任何非 GET。子收集器仍分别限制响应大小 / 读取次数并在请求前刷盘。
5. 对三份完整旧代码归档及子收集器结果 / 日志逐项校验，将其内容摘要绑定到候选身份和来源摘要。源码在收集前后再次检查。最终事实、父日志及结果文件完成写入 / fsync / close 后，才可返回可检查的本地证据。
6. `checkLocalEvidence` 必须提供同一四字段身份与证据摘要；复查活跃来源、实际预检产物、归档 / 日志 / 结果字节。超过本地 60 秒使用窗口、时间回拨、文件漂移或落盘不确定均拒绝复用；发现异常后该对象不可复活。

这个接口刻意只返回 `localEvidenceUnchanged=true`、`remoteStateRevalidated=false`，**不返回完整操作器所需的七个 true，也不提供 `preflight` / `assertReady` 放行回调**。本地文件一致不等于云端状态仍一致，更不等于 SQL 静默、独占或预算充足。

## 来源与信任边界

- `sourceFreeze` 是可信本地主机程序创建的活跃对象，不是允许任意插件 / RPC 提供的认证接口；磁盘 manifest 不能替代它。注入 `fetchImpl` / `io` 是本地测试接缝，不是凭合成响应建立真实环境资格的机制。
- 收集器仅作为冻结后的 bundle 使用。发现构建先确定来源，随后固定输入，再重建并测试；最终三份 Worker 和主机操作器也重新离线打包。固定 **443 个已存在文件、270 个缺省配置路径**，包含预检收集器及两个子收集器自身的来源。
- 本地文件按已打开句柄、64 KiB 块有界读取，并核对前后文件身份 / 大小 / 修改时间；不先用无界整文件读取再检查上限。源码 / 工具完整性仍承接 v283 的限制：不是排他文件锁、构建签名或对抗恶意 ABA 写者的原子证明。
- 本地 60 秒窗口不是云端证据统一新鲜度合同，也不是原生维护时序资格；同步文件 I/O 不能被计时器抢占。原有八个维护守卫与 **5/10/15 秒**限制未修改。

新增独立用例为 46 个；同一组对两个 bundle 重跑，不声称新增 185 个独立用例。关键反例包括：

- 伪造 / 缺失来源记录，异步“通过”函数，错候选、错 scope、错 prior worker，以及未冻结依赖均在首个 GET 前被拒绝。
- 403、版本 / settings 漂移、套餐缺失 / 改变、损坏 multipart、读期间源码变化、预先取消、超时及迟到响应不能形成可复用证据。
- 零进度写入、短写、首条 / FINISHED 日志 fsync、结果 fsync / close 故障被覆盖。即使磁盘上出现看似完整的文档，close 不确定也使活跃对象失效；不会将文档的存在当作成功。
- 归档代码 / 父日志 / 结果篡改、错误身份或摘要、时间回拨导致本地复查拒绝。
- 把部分证据交给**真实操作器**的合成 fixture，操作器停在 `preflight`，外部请求为 0。该测试只使用自己的临时 workspace 执行预约，不触碰真实项目预约。

另外，在实际 v283 来源冻结实现、三份真实 dry-run bundle 和实际预检 bundle 上完成一次组合接线，19 次合成 GET、约 **1,585 ms**；父日志 3 条、旧代码日志 35 条、套餐日志 10 条哈希链均核对。源 / scope / 候选 / 归档摘要一致，返回部分证据后，本地复查成功且明确不声称远端复查。这个用例使用公开、已过期的合成 grant，没有安装 Token 或线上许可。

保留了前两轮 165 / 181 项通过的中间结果和各自源码；最终 185 项结果覆盖当前实现，不累加重复执行。机器结果校验 **767 项直接文件摘要**，其中包含 v283 的 638 项直接产物，以及当前缺省路径与八个维护守卫；未重新验证所有历史依赖树。未重跑完整业务 suite / TypeScript、Node 22 或原生 Workers，不将打包当作原生运行验收。

## 边界与下一步

Cloudflare / Wrangler 技能用于保持固定 staging 资源边界、核对已安装的 `deploy --dry-run` / `--metafile`，并限制为离线构建。真实管理 API、云写入、部署、D1 SQL、公开 Worker、模型和 KMS 调用均为 **0**；未重新请求已有 403，也未把历史套餐快照当作本轮新的真实观察。累计 US$2 上限不重置，实际账单未刷新。

以下四类事实仍没有完整提供器，必须继续保留缺口：

- 全部调用路径：11 个 Zone 路由 403、Pages 身份 / 生命周期、Dispatch 等外部事实仍缺。
- 排他所有权：目录快照和用户允许测试不等于取得可验证的排他控制，也不等于在途 SQL 已静默。
- 首轮累计预算：US$1.20 历史 / 延迟费用预留与 US$0.80 未分配额不是已核验余额，不得重置累计 US$2。
- 原生维护时序：本机合成网络 / 文件样本不替代真实 Workers 资格。

下一步为这些领域建立可检查、同一身份的事实输入，并接入完整只读 `preflight` / 同步 `assertReady` 提供器；缺失、过期或相互矛盾时拒绝。**本轮没有完成该完整提供器，也没有放行真实 BYOK 验收。** C02.G / C01 及后续依赖保持未通过。
