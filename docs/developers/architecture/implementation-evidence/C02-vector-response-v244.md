# C02 v244：向量响应资源所有权

日期：2026-09-10；Checklist v1.143；LOCAL_PASS，未部署。

## 实现结果

Embeddings／rerank 在 fetch 返回后接入 `ownUpstreamResponse`，将响应源 EOF 与取消 ACK 传递给 failover 的资源汇总。错误 Content-Type、声明／实际正文超限、读取取消以及转交给后续消费者的非 2xx 正文均覆盖。零高水位包装不预读、不聚合 payload；解锁不当作取消确认。返回头、状态以及成功 JSON 校验、用量和金额算法保留。

四个公开入口（含 `/api/v1` 别名）在派发前登记资源任务。原始 fetch 未返回时，既有 attempt owner 继续持有容量；请求取消／deadline 后返回的正文也被取消并等待真实 ACK。记账不等待该 ACK，ACK 拒绝则保留数值预留。无重试、无第二次推理。详细边界见 [合同](../../reference/vector-response-resource-policy.md)。
