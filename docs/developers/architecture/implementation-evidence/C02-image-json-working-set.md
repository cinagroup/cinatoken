日期：2026-09-06。状态：**重复分配治理子集 LOCAL_PASS；C02 DOING，整个实例容量未通过**。执行/自检：Codex；独立 Reviewer 待指定。接续 [控制字段显式边界](./C02-image-control-boundaries.md)，不覆盖历史证据。

## 1. 本轮实现与不变合同

本轮修改两个运行时代码文件，处理从入口/普通响应解析到出站预检、按需发送的重复分配，不改变路由、供应商参数或账务决策。

- [分段解析器](../../../../packages/proxy/src/services/egress/segmented-json-response.ts)：没有引号、反斜杠或 U+0000–U+001F 的字符串片段直接复用已解码内容，避免再次拼引号并原生解析成第二份字符串。有转义/控制字符的片段仍交给原生 JSON.parse；完整结构仍在 EOF 后原生校验，长数字仍整体原生解析。没有放松语法、结构预算、重复键顺序或错误预览规则。
- [JSON 长度与编码器](../../../../packages/proxy/src/services/egress/stream-json-body.ts)：Content-Length 从 UTF-16 单元直接计算 JSON 转义后的精确 UTF-8 字节数，不再为字符串值或属性名构造转义副本或写入暂存编码区。正确计入引号/分隔符、短转义、六字节转义、Unicode、跨页代理对和孤立代理项；数字仍使用原生格式化以保留 -0、指数形式及非有限值转 null。保留结构预检、安全整数累计和长字段中每 8 KiB 字符检查取消/绝对时限。
- 同一编码器在真正发送时，对不含 JSON 转义字符或代理单元的片段直接编码原值；其余片段仍采用原生 stringify，保留跨页高代理项状态。发送页仍最多 64 KiB，生命周期、取消、错误、EOF 和所有权规则不变。数组计数与发送均按索引，不调用用户覆盖的 Symbol.iterator。

解析器共享的是不可变解码字符串，而不是可复用的网络字节缓冲；一个短切片可能保留它所属的有限解码页，因此不声称零拷贝或持有工作集完全下降。TextParts 仍将多段输入按有界页汇合；这不是所有值的零分配解析器。

生成 prompt 和七个未适配原生根字段沿用 v1.30 边界，未扩大 Guardrail 投影。入口 50 MiB、文件 20 MiB、普通上游 JSON 32 MiB、64 层/65,536 节点、BOM/UTF-8 替换、完整 EOF 后交付、unknown 禁止重放和用量结算均保持。默认参数仍不被暗中套用入口上限；SSE 仍按事件整体解析。

Workers 最佳实践技能实际推动了检查“有界片段仍会重复分配”的全处理路径，而非只看单页大小。依据 [Cloudflare 官方最佳实践](https://developers.cloudflare.com/workers/best-practices/workers-best-practices/)；最新 types registry 获取失败，采用已安装 Workers types 5.20260829.1 与 Wrangler schema。未改依赖、运行时兼容日期、flags、bindings 或云配置。

## 3. 内存证据与未改善部分

为分清两项优化，本轮先完整运行 24 组测量后再改运行时代码；仅改编码器后完整重跑，随后增加解析优化并再次完整重跑。测量脚本本身未修改，原始结果分别是 [修改前](./C02-image-json-working-set-before.json)、[仅编码优化](./C02-image-json-working-set-encoder-only.json)、[最终源码](./C02-image-json-working-set-memory.json)。每次均包含原生缓存控制、拼接长值控制、当前片段值三种实现；不是只保留最有利样本。

仅编码优化时，普通参考图出站准备后也降至约 53 MiB，但解析中离散观察最大仍约 94 MiB；追加解析优化后才进一步降到约 57 MiB。持有工作集没有相同幅度改善，最终 GC 后甚至有约 0.1 MiB 的小幅增加，符合片段/解码页仍被保留的边界。最后一行的测量不执行公开 prompt 预检，**不表示公开路由接受或发送 50 MiB 的有效提示词**。

最终 ASCII/混合参考图输出仍为 52,428,800 字节；替换参考图为 157,286,294 字节，接近 150 MiB。发送页仍最多 64 KiB，但最终完整发送组 ArrayBuffer 观察增量约 50–68 MiB；单独报告 heapUsed 下降不能证明全实例总内存达标，也不能把不同时间的各项最大值简单相加。最终当前片段模式取消/发送释放测量持有者、经过一个事件循环再 GC 后，堆增量约 2.45–2.56 MiB；不把显式 GC 或测量等待加入应用逻辑，不声称同步物理清零。

[18 组最终控制字段重跑](./C02-image-json-working-set-controls.json)继续执行完整 EOF、真实生成参数校验与上传 helper。当前分支的填充提示词/format/超限提示词/错误对象类型观察堆峰值约 65 MiB，替换解码提示词仍约 105 MiB；**未适配的 size 仍约 154 MiB，且仍发生 52,428,747 字符的整值还原**。该脚本的原生 15 字段分支使用当前解析器，不是 v1.30 完整历史实现；本轮修改前的可配对结果来自上述 24 组，而不是把两个分支伪装成历史版本。
