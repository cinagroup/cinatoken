仍使用独立 staging D1 `6bf5d41e-fe0b-4afa-9f67-ff5cf82e23d1`、控制 Worker `cinatoken-staging-recovery-control` 和私有接收端 `cinatoken-staging-usage-recovery`。沿用 0 / 0.10 / 0.20 合成美元三样本，18 条种子语句由真实仓库生成，用户及 API key 最终 disabled，使用本轮独占请求 UUID、用户、Workspace、模型统计标识。无上游凭据、真实模型调用或真实资金转账。

在 `user_audit_logs` 上安装一枚随机唯一名称的 `BEFORE INSERT` 触发器，只有同时匹配本轮 0.10 美元请求的 request_log_id、user_id、api_key_id 才 `RAISE(ABORT)`。DDL 标识及字符串均经过精确 UUID 格式验证；不接收任意 SQL 或用户请求内容。它不修改已有约束，也不插入伪造失败/成功结果。

既有关键 batch 中，回执和任务完成触发器、请求日志、模型统计、供应商尝试事实、预算预留终态及账户计数均在费用审计 INSERT 之前执行。因此在此处拒绝能够检查此前所有写入是否一起撤回，而不只是“第一条 INSERT 没有发生”。D1 文档说明 batch 中任一语句失败会中止或回滚整个序列；本轮实际核验其在当前结算路径上的表现。[D1 batch](https://developers.cloudflare.com/d1/worker-api/d1-database/)、[SQLite RAISE](https://www.sqlite.org/lang_createtrigger.html)

## 平台观察结果

未经认证和错误令牌各返回 403，确认保护生效后才发送有效零字节控制命令。公网本轮共 **5 次**，其中 3 次真实恢复 RPC：

| 阶段 | 本次 committed / deferred | 合成账户已支出 / 预留（微美元） | 故障请求状态 |
| --- | --- | --- | --- |
| 审计故障存在 | 2 / 1 | 200,000 / 500,000 | pending，revision 2，attempts 1 |
| 移除故障并确认已到期 | 1 / 0 | 300,000 / 0 | committed，revision 4，attempts 2 |
| 确认提交后重复调用 | 0 / 0 | 300,000 / 0 | 无变化 |

首次扫描 / 领取均为 3；故障样本的费用预留仍 dispatched、settled_micros=0，无该请求日志、供应商尝试事实、费用审计、日统计或回执。另两样本正常提交。该请求被记录为 `execution_error`，租约释放，任务 `available_at - updated_at = 5` 秒；不是 blocked、unknown、退款或重新获得推理许可。

数据库读回：updated_at=`1788772266`、available_at=`1788772271`，首次观察 now=`1788772268`；移除故障后，准入检查 now=`1788772273`、due=1。只有确认到期才发起恢复；未提前重新领取、改写任务时钟或手工标记完成。恢复仅扫描 / 领取 / 提交 1 项，回执 lease_revision=3，对应新租约；先前完成的两项不重复执行。最后一次所有任务计数为 0。

每个阶段都回读既有 11 组精确范围投影：账户、key、意图、快照、任务、预留、回执、日志、尝试事实、费用审计、模型日统计。快照摘要和原事件时间保持；最终 3 日统计各计数一次、两份费用审计、3 份回执/日志/尝试事实。最后两次投影完全相同。三次响应均为 `200 finished`、`retry_safe=false`，错误/延期由内部计数表达；不把 200 单独当作成功证据。
