# C02 v283：候选构建、来源冻结与字节绑定

2026-09-21，本轮完成本地两阶段来源冻结组件与真实离线构建接线。最终 **314 项测试通过**；三份 Worker 完成发现 / 验证两轮 dry-run，主机操作器完成两轮打包；固定 440 个已存在文件和 270 个缺省配置路径。**未部署，完整预检未通过。**

## 实现

新增 `scripts/deploy/byok-d1-source-freeze.mjs` 及专项测试。调用顺序为：发现构建的 metafile → `beginByokD1SourceFreeze` 捕获输入 → 重新构建并测试 → `seal` → 每次使用前 `assertCurrent` / `bindCandidate`。

- 固定 receiver / controller / gateway / operator 四个角色及入口；逐项核对 metafile 中的真实文件字节数、内部依赖、允许的内置模块、唯一入口、输出字节数及输入图一致性。不以调用者自选的少量文件摘要替代完整构建输入图。
- 捕获输入文件、根 / 包级配置与锁文件、指定验证脚本和上一个证据文件。沿输入路径记录存在及不存在的 package / TS / JS 配置候选；新出现的配置也会使原证明失效。完整工作区不是排他锁，未宣告原子快照。
- 只读取工作区内的规范路径，逐级检查链接；普通源码 / 产物目录链接不接受。单独支持实际安装工具所需的 pnpm 别名，目标须在工作区 `node_modules/.pnpm/`，将目标、解析候选及实际文件路径一并固定；别名改指向或新增编译器遮蔽路径会使检查失败。
- 实际存在两份 esbuild：主机为 **0.27.3**，Wrangler 使用 **0.28.1**。两条实际解析链、包装代码、包清单和平台二进制均纳入固定；另固定 Wrangler 入口 / 分发脚本 / schema、当前 Node **v24.14.1** 可执行文件字节。没有声称冻结整个工具安装目录或整个 `node_modules`。
- 文件哈希按 64 KiB 块计算，检查读取前后文件身份 / 大小 / 修改时间。metadata 最大 4 MiB、每图最多 2,000 输入、源集合最多 6,000 路径，文件累计读取限额 256 MiB；文件检查为同步 I/O，期限不能抢占阻塞的系统调用。
- 封存后重新检查源码、工具解析、Node、metafile、代码 / source map 和验证证据字节。任何观察到的漂移使对象永久失效；恢复旧字节也不能复活该对象。报告只表示最近一次检查通过，明确要求使用前再次验证。
- `bindCandidate` 校验三份实际代码与已封存产物一致，并绑定现有完整 deployment fingerprint、runId、prior manifest 和来源证据摘要。本轮用**公开合成、早已过期的 grant**把真实 bundle 接入此检查，没有生成安装 Token、真实执行 reservation 或有效线上许可。

这是信任本地构建驱动程序的完整性检查，不是可独立验证的构建签名或对抗恶意并发写者的锁；中途改写再恢复的 ABA 不由前后快照排除。日志 / JSON 的哈希只绑定内容，不自动证明其语义或测试充分性。组件明确保持 `fullPreflightPassed=false`、`atomicSnapshot=false`、`buildExecutionIndependentlyAttested=false`、`evidenceSemanticsVerified=false`，还不能直接充当整个操作器的 `sourcesFrozen` 准入证明。

## 失败与修正保留

1. 首次真实接线拒绝了依赖图中的 `cloudflare:sockets`；根据已安装官方类型补充精确内置模块，并限制为 Worker 角色，不允许任意 `cloudflare:*`。
2. 第二 / 第三次发现构建在固定工具文件时被本机 pnpm 链接拒绝；第三次增加安全的失败阶段标识。随后加入受限工具链接支持和改指向反例，而不是允许任意符号链接。
3. 第四次 310 项通过、1 项真实产物测试失败。独立只读探针证明 FormData **字符串字段**将 receiver 的 41,194 字节变为 41,997 字节，原因是换行规范化；Blob 文件字段保持 41,194 字节。仅修改发布测试夹具及新增混合 LF / CRLF / 孤立 CR / 中文用例，未修改上传或生产业务逻辑。此前发布测试源码已按原 SHA-256 归档。
4. 同时发现实际 Worker 编译器不是项目根目录那一份，补充真实解析链固定。第五次 314 项通过后，又将工具链接验证提前至包解析之前，并增加真实 bundle 与过期合成候选的绑定接线；最终再跑 **314/314**。

五个中间运行结果、日志、产物和各自源码快照均保留；旧成功样本不替代最终源码验证。本轮机器结果验证 638 项直接文件摘要、当前缺省路径状态，以及 v282 的六项直接证据和八个维护守卫；没有重验全部历史依赖树。

## 边界与下一步

Cloudflare / Wrangler 技能用于核对已安装命令、metafile 契约和固定 staging 离线配置。使用 `deploy --dry-run`，没有执行实际发布；构建子进程剥离凭据 / esbuild 覆盖变量，关闭指标与 dotenv 开发变量加载。管理 API、云写入、部署、D1 SQL、公开 Worker、模型、KMS 调用均为 **0**，累计 US$2 上限不重置，未刷新账单。

下一步在同一 C02 接入**有来源约束的完整只读预检提供器**：将来源固定与 prior-code、实际套餐、调用路径、独占、预算和时序证据绑定到同一次候选身份；缺项须明确拒绝，不能制造七个 true。仍有 11 个 Zone 403、Pages 身份 / 生命周期与 Dispatch 语义等待外部事实；不重复无新事实的查询。只有完整当次证明和原生维护资格齐备，才考虑真实 BYOK 独占验收。C02.G / C01 及后续依赖保持未通过。
