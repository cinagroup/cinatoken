操作器支持最多四轮、调用前读取原始 available_at 并等待自然退避，不修改时间。但本轮三类均在一轮内完成，**真实部分认领/退避后跨轮继续恢复仍未验收**。v1.74 的真实部分状态与本地自然退避证明不能拼接成这个线上结论。每次仅三项任务，也尚未覆盖配置允许的五项最大批次。
