# C02 v273：维护入口准备与新鲜度窗口解耦

2026-09-21，Checklist v1.172。**LOCAL_PASS / NATIVE_TIMING_PENDING**。本轮修正 BYOK 主机编排中的时序瓶颈及一次集成接线缺口；未部署，云端调用为 0。路由 403、完整预检、原生维护时序、C02.G / C01 仍未通过。

## 问题与修正

旧顺序是：STOP → seal → 关闭 gateway → 全入口关闭观察 → 签发维护许可 → 打开 controller Access / workers.dev → 清理。controller 两个开启操作共含 12 个管理 HTTP 请求；这些请求发生在观察之后，会消耗主机 10 秒、接收端 15 秒的新鲜度窗口。增加超时或把过期观察标为新鲜都不成立。

新的固定顺序：

```text
十用例独立核对 → STOP → 数据库围栏 closed → gateway / Access 关闭
  → 准备维护 controller（仅本次服务令牌、无 D1 绑定）
  → 两轮观察：生产入口关闭，仅受限维护入口已配置
  → 5 秒内条件签发一次性许可 → 10 秒主机检查 → 清理 HTTP
  → 原生 D1 15 秒检查 / 一次性认领 → 清理及回执
  → controller 关闭 / Access deny-all / 撤销令牌 → 全关闭观察 / 最终数据库核对
```

准备阶段尚无维护许可；因此开启受限的维护传输不授予删除权限。测试实际调用原接收端函数，证明此时返回拒绝且数据库行不变。仍要求全部十项用例验证、STOP、封闭和 gateway 关闭成功；任一未知结果不进入这条成功清理路径。

## 边界保持

- `createByokD1IngressClosure` 默认语义不变，仍要求所有已知入口关闭；新增显式维护模式，返回 **MAINTENANCE_READY**，不会返回 CLOSED。
- 维护模式保持 `knownIngressClosed=false`、`knownProducerIngressClosed=true`、`cleanupAuthorized=false`、`databaseQuiescenceProved=false`。只允许固定 controller 的 workers.dev 开启，预览、其他三个 Worker、域名、定时器及 gateway Access 仍须关闭 / 空。
- controller 的版本和 settings 仍与已验证的新部署绑定；另外核对固定三个启用 / audience 变量、唯一 `UsageRecovery` 服务绑定、无 D1 绑定和无 Tail。旧实验 controller 或任意开放 Worker 不能使用例外。
- Access 必须精确限定到本次拥有的服务令牌 ID；两轮完整令牌清单都须确认 ID 和 run 名称唯一匹配，旧令牌不可出现，不能把通用 allow / 其他令牌当成维护权限。
- 管理适配器只接受新的维护观察接口及同一 run，要求 controller 两步准备 ACK，才进行原来的单条条件 INSERT；数据库侧 5 秒签发条件和 60 秒许可不变。
- 主机 10 秒检查、原生 15 秒检查不延长。清理发送器新增必需的同步准入回调，**PENDING 刷盘后、真正发出 HTTP 前**重新检查；刷盘使窗口失效时零 HTTP，已消费尝试仍不重放。
- 成功路径仍为 93 条操作日志、三次双轮观察共 165 个逻辑 / 单页 GET。失败收尾仍是独立 STOP / seal / 关闭 / 撤销，不自动恢复旧实验、删除未知样本或移除持久围栏。

这是针对现有 staging 的操作顺序修正，不改变 Images 已确认的不可逆成功结算点，不修改 Worker 业务源码、D1 迁移 / 围栏 / 清理 SQL 或生产配置。

## 验证与失败保留

历史源码先按字节归档；保留旧顺序完整打包产物。对同一新增用例施加 **12 × 1500 ms = 18 秒虚拟管理请求延迟**：

- 旧顺序产物：0 PASS / 1 FAIL，停在 `open-controller`，不能继续清理。
- 修正后源码及打包版：该场景均通过，准备阶段的延迟发生在新鲜观察之前；没有用延长许可换取通过。

首轮四套件集成为 **204 PASS / 23 FAIL，共 227 项**，工具输出中保留。当时观察器已要求本次令牌名称，但只读传输仍仅返回 ID，导致后续路径统一停在 `closure-fresh`。修改前再次冻结完整中间产物，定向重现 0 PASS / 1 FAIL。随后读取器只补充可选且有界的名称字段，仍不返回 client secret / 其他凭据，也不在观察日志保存原始令牌正文；维护模式对缺少名称保持拒绝。
