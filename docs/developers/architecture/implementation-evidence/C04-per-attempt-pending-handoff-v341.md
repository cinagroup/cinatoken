# C04 v341: request-scoped per-attempt pending handoff

Status: **default off, no production economic producer**. The [quote attempt capture](../../../../packages/proxy/src/services/shared-key-quote-attempt.ts) now keeps each committed pre-fetch quote reference together with an observed transport stage. Chat's [failover dispatch](../../../../packages/proxy/src/services/failover-dispatch.ts) records a granted fetch boundary or ambiguous transport after a claim. The [OpenAI Chat driver](../../../../packages/proxy/src/services/egress/openai-driver.ts) reports the raw upstream HTTP status immediately when `fetch()` resolves, before body parsing or gateway normalization. The [Chat route](../../../../packages/proxy/src/routes/v1/chat.ts) passes one request-local typed handoff to its optional `recordUsageAndOutbox` hook. Enabling quote capture without that hook still returns 503 before dispatch.

The handoff contains the exact attempt, request, Key, transition and quote version IDs. Every per-attempt token count and provider cost remains `null` with certainty `unknown` and `manual_review` evidence. A final aggregate usage value, a 200 response, a 429 response, and a pre-send quote claim are not promoted to billable per-attempt facts. A late response after a transport-ambiguous deadline cannot rewrite the captured state. The existing economic event shape accepts these pending outcomes; the v340 consumer would leave them `pending_manual` without seller credit if a trusted producer committed them.

Verification: the [quote attempt tests](../../../../packages/proxy/src/services/shared-key-quote-attempt.test.ts), failover dispatch tests, and global model fallback tests passed **75/75** in one local run. These include loopback HTTP 429 to 200, socket loss with no replay, invalid 200 body, pre-fetch budget denial, and attempt identity ownership. Proxy dispatch safety also passed **4292/4292**, and Proxy full typecheck passed. The quote attempt test is registered in the local CI workflow; Linux CI has not run.
