## 精确边界与本地验证

原有恢复合同限制单份序列化快照不超过 262,144 个 UTF-8 字节。新增样本分别覆盖 ASCII、Unicode、密集 JSON、转义字符：

- 每种样本的 262,143 / 262,144 字节通过编码与解码；262,145 字节在编码和存储解码入口被拒绝。
- 原 SQL CHECK 对超限快照拒绝，真实 SQLite 事务回滚后无残留样本。Unicode 同时验证字符数量小于 UTF-8 字节数量。
- 每组含三笔合成任务，费用分别为 0、0.1、0.2；用户与 API key 在样本准备完成后均禁用。捕获真实 repository 的 INSERT/UPDATE，任务由原触发器创建，不插入伪造回执或已提交状态。
- 只扩大已允许的合成审计字段；不改变身份、金额、用量计数、出站意图或账务算法，也不在已有摘要后直接填充字节。
- 对真实 host/repository 链验证恢复、快照不变、原始大审计内容相等、重复调用、晚期事务回滚、提交确认丢失，以及不影响另一租户的精确清理。

新增共 **17 项**：初始边界/恢复 12 项，准入标志 2 项，分轮状态与自然退避 3 项。完整 staging 回归依次为 527、529，最终 **532/532**，无失败、取消或跳过；定向 staging 类型检查退出 0。它们是当前明确执行的 staging 测试链，不是整个仓库测试总数。

类型查询首次受本机沙箱对镜像站连接的限制；随后只读查询 npm 官方注册表，确认当前 Workers 类型为 5.20260907.1，没有安装或升级依赖。按 Workers 最佳实践和 Wrangler 技能区分本地证据与真实平台结果；本地通过不替代 Workers 物理容量验收。

### ASCII 的已完成证明

第二轮三份快照均精确为 262,144 字节，消费者提交全部三笔。每笔快照摘要和原始记录时间保持不变；有且仅有一份日志、回执、provider attempt，正费用任务各有一份 usage_charge 审计，账户合成已花费 300,000 micros、预留归零。

重复 RPC 的扫描/认领/提交等计数为 0，11 组账务投影不变。通过 D1 的标量相等性查询核对 raw_usage、pricing_audit、route_trace、timing_metadata 与原快照内容一致，重复调用后仍相同；没有为验收下载或打印大审计正文。

### 准入窗口的正确语义

原 runBudgetMs=5000 只停止**新增认领**，不是强制取消已经开始的 D1 事务。最后一笔完成后检查窗口，也可能使 admissionStopped=true。这个布尔值不能单独判为失败，更不能当作全部任务已完成的证明。

第三轮的真实结果为 scanned=3、claimed=3、committed=2、deferred=1，其余错误/不确定计数为 0。清理前两笔为 committed revision 2、attempts 1；第三笔为 pending revision 2、attempts 1、last_error=interrupted，无活跃租约。未完成任务恰为零费用任务，因此账户已花费 300,000 micros、预留为 0，**这并不代表全部三笔记账完成**。

新增分轮校验根据实际提交集合计算金额、预留、日志、回执和统计，并将每轮认领/提交/退避计数与状态增量逐项匹配，不预设一次 RPC 能完成三笔。每份回执 lease revision 必须对应真实结算认领次数，而 provider attempt 仍只保留原始推理事实。

本地真实 SQLite 验证认领前停止，以及认领后 interrupted 的原有 5 秒退避；等待数据库自然到期，不 UPDATE 时间或模拟 D1 时钟。随后新一轮补齐、回执 revision 正确，重复调用不变。第四轮线上操作器已加入最多四次显式续跑及每次调用前的真实到期检查，但因 seed 传输超时，**这套分轮过程尚未线上执行**。

### 管理 API 超时仍需诊断

第二、四轮的 Unicode seed 在客户端分别等待 20 / 45 秒后超时；后续读取均发现三个完整 pending revision 0 任务，用户/key 已禁用，合成预留 1,000,000 micros。可确认写入耐久事实，不能确认当时响应已交付，也不能据此推断根因是网络、服务端处理或请求尺寸。

这两次没有发送 Unicode 恢复 RPC，也没有把“超时”等同于写入未发生。超时请求未返回成功 meta，故该部分真实行读写量未知。继续增大超时或重复批量 seed 不是下一步；应先用无状态变更的、分尺寸的只读请求定位管理传输问题。

当前 [D1 限额文档](https://developers.cloudflare.com/d1/platform/limits/) 区分单行/字符串 2,000,000 字节、SQL 文本 100,000 字节、每查询 100 个绑定参数，并指出 REST API 调用及整批执行期限。262,144 字节是应用自身快照上限；样本采用参数绑定，不能将这个上限误当作 SQL 文本长度。符合静态限额也不等于端到端请求必定完成。
